# 🍔 McDonald's Sales Dashboard (Excel Project)

## 📊 Overview
This project is an interactive **Sales Dashboard built in Microsoft Excel** to analyze McDonald's sales performance. It provides insights into revenue, order trends, product performance, and customer ordering patterns.

---

## 🚀 Features
- **Total Sales & Orders Overview**
  - Total Sales Revenue
  - Total Orders
  - Average Order Value
  - Average Price per Item

- **Sales Analysis**
  - Weekday vs Weekend sales comparison
  - Monthly sales trends
  - Order volume by time of day (Morning, Afternoon, Evening, Night)

- **Product Insights**
  - Top 5 best-selling products
  - Category-wise revenue analysis

- **Order Behavior**
  - Order distribution by day of the week
  - Time-based ordering patterns

---

## 🛠️ Tools & Technologies Used
- Microsoft Excel
- Power Query (Data Cleaning & Transformation)
- Data Modeling (Relationships between tables)
- Pivot Tables & Pivot Charts
- Slicers & Interactive Filters

---

## 🗂️ Data Model
The project uses two main tables:
1. **Order Details**
   - Order ID, Date, Time
   - Item ID, Price
   - Day Name, Workday Type

2. **Menu Table**
   - Item ID
   - Item Name
   - Category
   - Price

➡️ Relationship:  
`Order Details (Many) → Menu (One)` via Item ID

---

## 📈 Key Insights
- Higher sales observed during **Afternoon & Evening**
- **Burgers and Chicken items** generate maximum revenue
- Weekdays contribute more consistent sales than weekends
- Monthly trend shows fluctuations indicating seasonal demand

---

## 🎯 Purpose
The goal of this dashboard is to:
- Simplify sales data analysis
- Help in identifying top-performing products
- Understand customer behavior
- Support data-driven business decisions

---

## 📌 How to Use
1. Open the Excel file
2. Use slicers (Day Name, Time Period) to filter data
3. Analyze charts and KPIs for insights
